Privacy Policy

How YL Imagination Squad Automation handles data when it publishes to the Instagram and TikTok accounts @yl_imagination_squad.

Operator: Yerik Linares Effective: September 5, 2026 Contact: yeriklinares@gmail.com

Short version

This automation only ever acts on the operator's own TikTok and Instagram accounts. It does not collect data from, or about, any other person. There are no other users, no sign-up, and nothing to opt into or out of beyond the operator's own platform authorizations.

Data it accesses

DataSourcePurpose
OAuth access token for @yl_imagination_squadTikTok Login Kit / Content Posting APIAuthorize publishing videos to that one account
Basic profile info (display name, avatar, open ID)TikTok user.info.basic scopeConfirm the token belongs to the correct account before posting
Recent post captions/timestamps for @yl_imagination_squadInstagram Graph APIAvoid repeating the same tip/topic on consecutive days

No data is read from any account other than the operator's own. No visitor, follower, or commenter data is collected or stored.

Data it generates

Post images and short videos are produced with AI image/video generation tools, from prompts the operator's automation writes itself (photography tips). No personal photos, uploaded user content, or third-party data are used as generation inputs.

Storage and retention

Platform access tokens are held by the operator's automation-hosting provider (Composio) to authenticate API calls, and are not exported, sold, or shared with any additional party. Generated media used for a single day's post is discarded after publishing; nothing is retained beyond what the TikTok and Instagram platforms themselves store for the published post.

What is never done

  • Selling, renting, or sharing any data with advertisers or third parties.
  • Reading messages, followers, or analytics belonging to any account other than the operator's own.
  • Using platform data to train AI models.
  • Posting, following, liking, or messaging on behalf of any account except @yl_imagination_squad.

Revoking access: the operator can revoke this app's access at any time from TikTok's or Instagram's own account settings, which immediately invalidates the stored token.

Changes to this policy

This policy is updated if the automation's data use changes — for example, if a new platform is connected. The effective date above reflects the latest revision.

Contact

Questions or data-related requests can be sent to yeriklinares@gmail.com.
